# 🏛️ GrievAI — AI Smart Public Grievance System

> An AI-powered public grievance platform that helps citizens report civic issues easily and enables authorities to analyze, prioritize, route, and resolve complaints faster.

---

## 📌 About the Project

**GrievAI** is a smart public grievance management system designed to improve the way citizens report municipal and civic problems.

Citizens can submit complaints using text, voice, images/videos, and location information. The system analyzes the complaint, identifies its category, determines priority, checks for possible duplicate complaints, and automatically routes it to the appropriate government department.

Authorities can use the administrative dashboard to monitor complaints, assign officers, update complaint status, and view AI-generated recommendations.

---

## 🎯 Problem Statement

Traditional public grievance systems often involve:

- Manual complaint registration
- Incorrect department routing
- Delayed responses
- Duplicate complaints
- Difficulty identifying urgent issues
- Limited complaint tracking
- Poor visibility for administrators

These problems can result in delays in resolving important public issues.
